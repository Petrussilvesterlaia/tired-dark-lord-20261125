A small Python program that writes a roughly 100-word fantasy villain monologue to /output/entry.txt. The monologue belongs to a weary dark lord who keeps putting off his evil plans, and the program checks the word and character counts, then reads the file back to make sure its contents are identical.

## Run it

```sh
python3 main.py
```

The program validates the monologue (100 words, ≤600 characters) before writing it.
